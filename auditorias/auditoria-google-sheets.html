02 · Estrategia de Sincronización

Cuándo y Cómo Sincronizar

Dos modos complementarios — se usan juntos según el tipo de dato

✓ Recomendado
⚡ Push en evento

Sync al guardar / aprobar

Cada vez que ocurre una acción importante en el servidor, se escribe la fila en Sheets inmediatamente. Sin delay, sin polling.

Datos en Sheets al instante
Sin consumo extra de recursos
Ideal para cotizaciones y pagos
Si Sheets falla, la operación local no se revierte
Requiere manejo de errores robusto
🕐 Batch programado

Resync completo nocturno

Un cron job que corre cada noche limpia las hojas y vuelca todos los datos del día. Actúa como safety net para no perder nada.

Garantiza consistencia total
Corrige discrepancias acumuladas
Ideal para el resumen financiero mensual
Datos en Sheets con hasta 24hs de delay
Requiere limpiar y reescribir hojas enteras

const { google } = require('googleapis'); // ── Configuración ──────────────────────────────────────────────── const SHEET_ID = process.env.GOOGLE_SHEET_ID; const auth = new google.auth.GoogleAuth({ keyFile: 'credentials/google-service-account.json', scopes: ['https://www.googleapis.com/auth/spreadsheets'] }); const sheets = google.sheets({ version: 'v4', auth }); // ── Función base ───────────────────────────────────────────────── async function appendRow(sheetName, row) { try { await sheets.spreadsheets.values.append({ spreadsheetId: SHEET_ID, range: `${sheetName}!A:Z`, valueInputOption: 'USER_ENTERED', insertDataOption: 'INSERT_ROWS', requestBody: { values: [row] } }); console.log(`[SHEETS] ✅ Fila agregada en "${sheetName}"`); } catch (err) { // NO propagar el error: el fallo de Sheets no debe frenar la operación local console.error(`[SHEETS] ❌ Error en "${sheetName}":`, err.message); } } // ── Formatters por módulo ──────────────────────────────────────── const SheetsSync = { /** Llamar después de aprobar cotización de Gremio */ async cotizacionGremio(cot, vendedorNombre) { const fecha = new Date(cot.fecha).toLocaleDateString('es-AR'); const productos = (cot.productos || []) .map(p => p.producto || p.categoria).join(' | ') || 'Varios'; await appendRow('Cotizaciones_Gremio', [ fecha, `COT-${cot.id.slice(-6).toUpperCase()}`, cot.cliente?.nombre || cot.cliente?.name || '', cot.cliente?.telefono || '', vendedorNombre || 'Sistema', cot.subtotal || 0, cot.iva || 0, cot.totalCliente || 0, cot.costoTotal || 0, cot.ganancia || 0, cot.anticipo || 0, cot.saldo || 0, cot.estado || 'pendiente', productos ]); }, /** Llamar después de aprobar cotización de Clientes */ async cotizacionCliente(cot, vendedorNombre) { const fecha = new Date(cot.fecha).toLocaleDateString('es-AR'); await appendRow('Cotizaciones_Clientes', [ fecha, `COT-${cot.id.slice(-6).toUpperCase()}`, cot.cliente?.nombre || '', cot.cliente?.telefono || '', vendedorNombre || 'Sistema', cot.subtotal || 0, cot.iva || 0, cot.totalCliente || 0, cot.costoTotal || 0, cot.ganancia || 0, cot.anticipo || 0, cot.saldo || 0, cot.estado || 'pendiente' ]); }, /** Llamar al registrar gasto o ingreso */ async movimientoFinanciero(mov) { const fecha = new Date(mov.fecha).toLocaleDateString('es-AR'); await appendRow('Movimientos_Financieros', [ fecha, mov.tipo, mov.descripcion, mov.monto, mov.categoria || '', mov.referencia || '' ]); }, /** Llamar al crear o actualizar trabajo */ async trabajo(work) { const fecha = new Date(work.createdAt).toLocaleDateString('es-AR'); await appendRow('Trabajos', [ fecha, work.clientName || '', work.clientPhone || '', work.total || 0, work.paidAmount || 0, work.balance || 0, work.paymentStatus || 'pending', work.status || 'pending', work.priority || 'normal', work.deliveryDate || '', new Date().toLocaleString('es-AR') ]); } }; module.exports = SheetsSync;

05 · Pasos de Configuración

Setup Paso a Paso

Proceso completo desde cero — incluye la consola de Google Cloud

01

Crear proyecto en Google Cloud Console

Ir a console.cloud.google.com → Crear proyecto "MR Letreros". Habilitar la API: buscar "Google Sheets API" y activarla. Sin este paso, no hay acceso programático.

Google CloudAPI
02

Crear Service Account y descargar credenciales

En Google Cloud: IAM → Service Accounts → Crear cuenta. Rol: "Editor". Generar clave JSON. Guardar como credentials/google-service-account.json en el servidor. Agregar al .gitignore — nunca subir al repositorio.

Google CloudCredenciales
03

Crear el Spreadsheet y compartirlo con la Service Account

Crear un nuevo Google Sheets. Compartir con el email de la Service Account (termina en @...iam.gserviceaccount.com) con rol "Editor". Copiar el ID del spreadsheet desde la URL y pegarlo como variable de entorno GOOGLE_SHEET_ID.

Google SheetsPermisos
04

Crear las 6 hojas con encabezados

En el spreadsheet crear las pestañas: Cotizaciones_Gremio, Cotizaciones_Clientes, Movimientos_Financieros, Trabajos, Clientes, Resumen_Mensual. Agregar la fila de encabezados en cada una y formatear como texto/moneda.

Google Sheets
05

Instalar dependencias en el servidor

Instalar el SDK oficial de Google y el cron runner. Agregar GOOGLE_SHEET_ID al archivo .env.

npm install googleapis node-cron
Node.jsSDK
06

Crear utils/sheets-sync.js e integrarlo en server.js

Copiar el módulo de la sección anterior. En server.js, importarlo y llamar los métodos correspondientes después de cada operación de guardado o aprobación. El patrón .catch() garantiza que un fallo en Sheets no rompe la operación interna.

BackendAutomático
07

Configurar el cron de resync nocturno

Crear utils/sheets-resync.js con la lógica de borrado y reescritura completa. Iniciar el cron en server.js. Probar manualmente con node utils/sheets-resync.js antes de activar el cron.

BackendCron
08

Agregar botón "Sync Manual" en el panel de admin

En la futura página usuarios.html (o en el top-bar del sistema), agregar un botón que llame a POST /api/admin/sheets/resync. Permite forzar una sincronización completa sin esperar el cron nocturno.

06 · Riesgos y Limitaciones

Qué Tener en Cuenta

🔴 Crítico

Credenciales en el servidor

El archivo service-account.json da acceso total a la hoja. Nunca subirlo a Git. Usar variables de entorno o un secret manager. Rotar las credenciales si hay una brecha.

🔴 Crítico

Sheets NO es la fuente de verdad

Los datos del sistema viven en los JSON del servidor. Google Sheets es solo lectura/reporte. Nunca editar directamente en Sheets y esperar que se actualice el servidor.

🟡 Importante

Cuota de la API: 300 req/min

Con muchas cotizaciones simultáneas se puede llegar al límite. El módulo de resync nocturno usa batchUpdate en lugar de múltiples append para minimizar requests.

🟡 Importante

Datos sensibles en Sheets

Los márgenes de ganancia y costos van a la hoja. Configurar permisos de visualización en Sheets de forma granular — la hoja de Resumen_Mensual puede compartirse con el contador sin que vea la de Cotizaciones completa.

🟢 Menor

Fallo de Google no bloquea el sistema

Por diseño, el sync es asíncrono y usa .catch() silencioso. Si Google Sheets falla, el sistema interno sigue funcionando normalmente. El resync nocturno recuperará los datos faltantes.

🟢 Menor

Límite de 10M celdas por Spreadsheet

Para el volumen de MR Letreros es prácticamente imposible alcanzarlo. Si el historial crece mucho, se puede archivar un Spreadsheet anual y crear uno nuevo por año.
