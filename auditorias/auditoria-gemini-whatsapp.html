02 · Casos de Uso

Qué Puede Hacer Gemini en el Bot

Capacidades específicas que mejoran la calificación de leads

🔍 Análisis de Intención

Gemini detecta si el cliente solo está "viendo precios" o tiene un proyecto real.

Cliente: "Cuánto sale más o menos un letrero?"
Gemini detecta: ❄️ Frío (consulta vaga, sin detalles)

Cliente: "Necesito cotización para 3 cajas de luz de 1.5x1m con iluminación LED para mi cadena de locales"
Gemini detecta: 🔥 Caliente (específico, múltiples unidades, B2B)

⏰ Detección de Urgencia

Identifica keywords de urgencia aunque el cliente no responda la pregunta directamente.

Cliente: "Inauguramos el viernes y todavía no tengo el cartel"
Gemini detecta: Urgencia extrema (+30 pts)

Cliente: "Es para más adelante, voy viendo"
Gemini detecta: Sin urgencia (0 pts)

💰 Inferencia de Presupuesto

Estima el presupuesto aunque el cliente no lo diga explícitamente.

Cliente: "Necesito algo económico, básico"
Gemini infiere: Presupuesto bajo (<$20k)

Cliente: "Queremos algo de primera calidad para nuestra sede central"
Gemini infiere: Presupuesto alto ($50k+)

🏢 Identificación B2B vs B2C

Detecta si es empresa (Tier A probable) o particular (Tier C probable).

Cliente: "Soy de RH de Telecom, necesitamos señalética"
Gemini detecta: B2B corporativo (+25 pts)

Cliente: "Es para el cumple de mi hijo"
Gemini detecta: B2C personal (0 pts)

🔄 Preguntas de Seguimiento Dinámicas

Gemini hace preguntas relevantes según lo que ya se dijo.

Si el cliente menciona "local" → Gemini pregunta ubicación y tamaño

Si dice "evento" → Gemini pregunta fecha y tipo de evento

Si dice "empresa" → Gemini pregunta cuántas sucursales

😤 Manejo de Objeciones

Responde dudas comunes sin necesidad de vendedor humano.

Cliente: "Pero ustedes son muy caros"
Bot con Gemini: "Entiendo la preocupación por el precio. Te cuento que trabajamos con diferentes materiales y podemos ajustarnos a tu presupuesto. ¿Cuánto tenías pensado invertir?"

04 · Arquitectura de Integración

Cómo se Conecta al Bot Existente

Modificaciones mínimas — el bot sigue funcionando igual, solo se agrega Gemini

🔄 Flujo Sin IA (actual)

Cliente escribe mensaje ↓ Bot busca conversación activa ↓ Valida respuesta (debe ser 1, 2, 3 o 4) ↓ Suma puntaje según opción elegida ↓ Pasa a siguiente pregunta ↓ Al terminar: calcula tier (hot/warm/cold)

🧠 Flujo Con IA (propuesto)

Cliente escribe mensaje (texto libre) ↓ Bot busca conversación activa ↓ Gemini analiza el mensaje completo ↓ Gemini extrae: intención, urgencia, presupuesto ↓ Gemini asigna puntaje (0-140) ↓ Gemini genera pregunta de seguimiento contextual ↓ Al acumular info suficiente: tier final

/** * Analiza el mensaje del cliente con Gemini y extrae información clave * @param {string} mensajeCliente - Lo que escribió el cliente * @param {array} historial - Mensajes previos de la conversación * @returns {object} { score, siguientePregunta, resumenAnalisis } */ async function analizarConGemini(mensajeCliente, historial = []) { // Construir el prompt para Gemini const prompt = ` Eres un asistente de ventas experto en calificar leads para un negocio de letreros y gráfica. CONTEXTO DEL NEGOCIO: - MR Letreros fabrica: letreros corporales, luminosos, vinilos, señalética - Clientes ideales: empresas (B2B) con presupuesto $20k+ y necesidad urgente - Leads fríos: particulares sin presupuesto definido que "solo preguntan" HISTORIAL DE LA CONVERSACIÓN: ${historial.map(h => `${h.rol}: ${h.mensaje}`).join('\n')} ÚLTIMO MENSAJE DEL CLIENTE: "${mensajeCliente}" TAREA: Analiza el mensaje y devuelve un JSON con: 1. "score": número de 0 a 30 según estos criterios: - Urgencia (0-10): ¿Es urgente? Keywords: "ya", "urgente", "esta semana" - Presupuesto (0-10): ¿Tiene dinero? Keywords: "presupuesto", monto específico, "no importa el precio" - Seriedad (0-10): ¿Es proyecto real? Detalles específicos vs vago 2. "insights": objeto con: - "esEmpresa": boolean (detecta si es B2B) - "urgencia": "alta" | "media" | "baja" | "ninguna" - "presupuestoEstimado": "alto" | "medio" | "bajo" | "indefinido" - "intentoReal": boolean (¿Es consulta seria o solo pregunta?) 3. "siguientePregunta": string - La pregunta más inteligente para hacerle ahora (debe ser natural, conversacional, y extraer info que falta) 4. "resumen": string breve de lo que entendiste RESPONDE SOLO CON EL JSON, SIN EXPLICACIONES ADICIONALES. `; try { const result = await model.generateContent(prompt); const responseText = result.response.text(); // Extraer JSON de la respuesta (a veces Gemini agrega ```json) const jsonMatch = responseText.match(/\{[\s\S]*\}/); if (!jsonMatch) { throw new Error('No se pudo parsear respuesta de Gemini'); } const analisis = JSON.parse(jsonMatch[0]); console.log('🧠 Gemini analizó:', analisis); return analisis; } catch (err) { console.error('❌ Error en Gemini:', err); // Fallback: si Gemini falla, usar lógica básica return { score: 10, insights: { esEmpresa: false, urgencia: 'baja' }, siguientePregunta: '¿Cuándo necesitarías este trabajo?', resumen: 'Análisis manual (Gemini no disponible)' }; } }
