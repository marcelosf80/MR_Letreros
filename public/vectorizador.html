Claves de API — Herramientas IA

Las claves se guardan solo en el servidor (archivo bot_config.json), nunca en el navegador. Si te aparece "token vencido" al crear con IA, pegá acá la clave de Google Gemini y tocá Guardar.

⚠️ Claves nuevas AQ.… vs clásicas AIzaSy…: Google está migrando las claves de Gemini y las nuevas que genera AI Studio (AQ.…) están siendo rechazadas por la API en muchas cuentas (error 401 ACCESS_TOKEN_TYPE_UNSUPPORTED, un problema del rollout de Google, no de tu sistema). Si la prueba devuelve ese error, creá una clave clásica en console.cloud.google.com → APIs y servicios → Credenciales → Crear credenciales → Clave de API y restringila a "Generative Language API". Esa clave AIzaSy… con restricción sigue funcionando.
